# Branch Line

A calm idle railway game for the browser. Link neighbouring stations, run trains, and fit parts drawn at random quality from the workshop.

## Play

Open `index.html` in a browser, or host the folder as a static site (GitHub Pages: Settings → Pages → Deploy from branch → `main` / root). No build step and no external requests. Progress is saved in the browser's local storage.

## Files

- `index.html`: page markup
- `css/style.css`: styles, light and dark themes
- `js/game.js`: game state, economy, workshop, map rendering and effects
- `js/audio.js`: generated ambient music and train sounds (Web Audio, no audio files)
- `fonts/`: Barlow and Barlow Condensed (SIL Open Font License)
